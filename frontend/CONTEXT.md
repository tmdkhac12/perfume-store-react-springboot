# CONTEXT.md

## Domain Language

- **Perfume Store**: E-commerce platform for perfumes.
- **Public**: Unauthenticated users browsing the store.
- **User**: Authenticated customers managing profiles and orders.
- **Admin**: Staff managing products, brands, and operations.

## Architecture

- **Frontend**: React (TypeScript) with Tailwind CSS.
- **Backend**: Spring Boot (planned integration).
