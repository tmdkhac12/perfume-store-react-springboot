# Domain docs

This repo uses a single-context layout for domain documentation.

## Consumer rules

- **Domain language**: Read `CONTEXT.md` at the repo root to learn the project's domain language and ubiquitous terms.
- **Architectural decisions**: Read `docs/adr/` for past architectural decisions.
- **Updates**: When making significant changes, update `CONTEXT.md` and/or record a new ADR in `docs/adr/`.
