# Triage labels

The `triage` skill uses the following labels to move issues through its state machine.

| Role              | Label             |
| ----------------- | ----------------- |
| `needs-triage`    | `needs-triage`    |
| `needs-info`      | `needs-info`      |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix`         | `wontfix`         |
