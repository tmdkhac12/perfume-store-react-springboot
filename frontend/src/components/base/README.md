# Base Components

This folder contains reusable UI primitives introduced in Phase 2.

- `Button`: Standard button variants (`primary`, `secondary`, `ghost`) and sizes.
- `Input`: Labeled text input with helper and error states.
- `Badge`: Compact status label with semantic tones.
- `Card`: Generic surface container for grouped content.
- `SectionHeader`: Reusable page/section heading block.
- `Breadcrumbs`: Navigation context trail.
- `ModalShell`: Shared modal container structure.
- `TableShell`: Reusable table scaffold with empty state.
- `PaginationShell`: Pagination controls for list/table pages.

Use these components as the default building blocks for migrated pages to keep UI behavior and spacing consistent.
